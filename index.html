One consistent visual language

A boxed × marks an irreversible step, a star marks a rate-limiting step, and every new pathway added to the map follows the same colour and symbol rules.

Carbohydrate metabolism map

Gluconeogenesis runs up the left, glycolysis down the right, meeting at glucose and pyruvate; one oxaloacetate branch point feeds both the Krebs cycle and gluconeogenesis. Below that: the electron transport chain, the glycerol 3-phosphate shuttle, glycogen metabolism, fructose / galactose / polyol, the pentose phosphate pathway, GAGs and glycoproteins, the four places NADPH is spent (glutathione, the respiratory burst, nitric oxide and cytochrome P450), and the three second messenger systems — all joined to the main map by dashed linking arrows. Tap any enzyme name to see where in the cell it works and which vitamin it runs on. Quantities are per glucose (×2 below the aldolase split).
